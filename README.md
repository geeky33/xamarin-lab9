# Experiment 9 - Widgets demo (.NET MAUI, successor of Xamarin.Forms)
Widgets: ContentPage, ScrollView, VerticalStack/HorizontalStackLayout, Grid, Label, Image,
Border (card), Button, Entry, Switch, CollectionView (horizontal), ActivityIndicator.

Open WidgetDemoMaui.csproj in Visual Studio 2026, pick an Android emulator, press F5.
CLI:  dotnet build -t:Run -f net10.0-android
